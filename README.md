# With Me

By Ampere Qiu · 2026

A mobile-friendly educational app for practising supportive conversations with Annie, a fictional friend experiencing depression. Five situations offer response choices, contextual feedback, and optional reflection. Learning resources and crisis guidance remain available throughout.

## GitHub Pages

Publish the main branch from the repository root in Settings → Pages → Deploy from a branch. The `.nojekyll` file keeps the site static. No build step or API key is needed. Relative asset paths and fragment navigation work under a repository URL such as `/with-me/`.

## Local preview

Run `python3 -m http.server 8000` from this folder, then open `http://localhost:8000`.

## Privacy and content

The app does not store reflections or use analytics. It does not require a visitor account. The conversations are illustrative and do not predict how an individual will respond. Crisis contacts link to current service information and should be reviewed periodically.
